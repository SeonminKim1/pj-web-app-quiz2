# 플레이스토어 등록 자료

Play Console에 그대로 붙여 넣는 문구입니다. 앱이 하는 일과 어긋나지 않게, 기능을 바꾸면 여기도 고칩니다.

## 기본 정보

- 앱 이름(30자): `퀴즈 놀이터`
- 카테고리: 게임 → 퀴즈
- 연락처 이메일: Play Console에 따로 입력(스토어에 공개됨)
- 웹사이트: https://quiz-noriteo.netlify.app
- 개인정보처리방침: https://quiz-noriteo.netlify.app/privacy

## 간단한 설명(80자)

```
넌센스 퀴즈 546문제! 방해꾼 동물을 피해 풀고, 친구한테 문제를 내 보세요
```

## 자세한 설명(4000자)

```
말장난 가득한 넌센스 퀴즈 546문제를 스테이지로 풀어 보세요.

■ 방해꾼 동물이 훼방을 놓아요
토끼, 강아지, 고양이, 다람쥐 중 방해꾼을 골라요. 풀고 있으면 문제 위에 올라앉아 가리고, 힌트를 열거나 틀리면 달려와서 놀려요. 잡아서 치우거나 간식을 주며 달래 보세요.

■ 막히면 힌트
문제마다 힌트가 3단계까지 있어요. 첫 힌트는 무료, 나머지는 문제를 맞혀 모은 골드로 열어요.

■ 친구한테 문제 내기
풀던 문제를 링크 하나로 단톡방에 낼 수 있어요. 받은 친구는 앱 없이 바로 풀어요.

■ 이런 분께
· 쉬는 시간에 가볍게 머리 식히고 싶을 때
· 친구, 가족과 퀴즈 내기를 하고 싶을 때
· 아재개그, 말장난을 좋아한다면

회원 가입 없이 바로 시작해요. 진행 상황은 이 기기에만 저장돼요. 한 번 연 뒤에는 인터넷이 없어도 풀 수 있어요.
```

## 앱 콘텐츠 답변(제안)

실제 제출 전에 Play Console의 질문 문구를 읽고 확인하세요.

- **광고**: 없음. (AdMob 등을 넣으면 "있음"으로 바꾸고 개인정보처리방침도 고친다.)
- **앱 액세스 권한**: 모든 기능을 제한 없이 사용 가능(로그인 없음).
- **콘텐츠 등급**: 폭력·성적 콘텐츠·도박·사용자 간 소통 없음. 공유는 외부 메신저로 링크를 보내는 것뿐.
- **타깃층**: 13세 이상을 권장. 13세 미만을 포함하면 가족 정책(광고·통계 SDK 제한)이 적용된다.
- **데이터 보안**
  - 데이터 수집: **예** — 앱 활동 → 앱 상호작용(페이지 방문, 공유 버튼 사용 횟수), 목적은 분석. GoatCounter로 보낸다.
  - 공유(제3자 제공): 아니요. GoatCounter는 서비스 제공업체로 처리만 한다.
  - 처리 방식: 사용자 식별에 쓰지 않음, 전송 중 암호화(HTTPS).
  - 삭제 요청: 계정이 없어 사용자와 연결된 데이터가 없음.
  - 진행 상황·설정·닉네임은 기기 안에만 저장하므로 "수집"에 해당하지 않는다.
